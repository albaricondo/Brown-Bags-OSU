# Sign Up Sheet

La tabla publica real vive en `data/signups.json` y se muestra en la pagina principal.

Si alguien completa el formulario de GitHub, el workflow copia esa inscripcion a la tabla publica automaticamente.

## Modo de uso

- Comparte el enlace de GitHub Pages.
- La gente abre el boton de inscripcion.
- Cada respuesta nueva queda guardada en el repo y visible en la tabla.
